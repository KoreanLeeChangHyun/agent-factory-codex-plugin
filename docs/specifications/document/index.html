Agent Factory Document

진입 계약

정확히 세 논리 문서 유형을 정의·작성·조회·관리한다. 원본 문서(Original)는 출처에 충실한 증거, 가공 문서(Processed)는 변환된 비권위적 작업 지식, 명세 문서(Specification)는 수락·조정된 지식으로 하나의 안정적 식별자 아래 충실한 한국어 Human 브라우저 표현 하나와 AI Skill 하나를 갖는다. 네 번째 유형이나 폐기된 역할을 도입하지 않는다.

Original -> Processed -> Specification은 가능한 증거·파생 관계만 나타내며 필수 흐름, 승격, 성숙도, 완전성 또는 일대일 대응이 아니다. 관계는 없거나 다대다일 수 있다. 실제 관계에 조회 가능한 출처 이력을 남긴다. 우선순위, 날짜, 담당자, 수락, 완료와 위험 수용은 명시적 Human 결정이 필요하다.

소유권과 실행

선택된 인증 클라우드 MCP 애플리케이션이 새 문서 저장, 리비전 게시, 색인·검색과 문서 설정을 소유한다. document_import, document_read, document_write, document_search, document_index, document_prepare_upload 또는 document_finalize_upload를 쓰기 전에 제공된 스키마·안내를 읽는다. 실제 승인된 테넌트와 대상을 확인하며 도구·연결·권한이 없으면 로컬 백엔드로 우회하지 않고 실패를 보고한다. ../mcp/docs/cloud-documents.md는 개발 소스 위치이며 설치 필수 경로가 아니다.

Gather는 클라우드 연동을 통한 외부 선택·수집을 소유하고 Document는 확인된 문서 대상의 작업을 소유한다. Explorer는 Convention 소유 Work 역량으로 명세를 수락하지 않고 원본·가공 증거를 만들 수 있다. Tool은 역량·연결 생명주기를 확인하고 Agent는 실행 권한, 로컬 세션, 그래프와 영수증을 소유한다. Workspace는 소유자 근거가 있는 상태를 표시하며 독립 문서 저장소가 되지 않는다.

게시 소스와 완료

Git은 배포 Skill 작성 소스를 소유한다. 이 플러그인의 여섯 안정적 쌍은 skills/<id>/와 docs/specifications/<id>/에 있으며 버전 관리되는 한국어 HTML은 게시 소스다. 패키지 상대 상호 위치는 소비자 런타임 경로나 독립 편집 가능한 두 번째 클라우드 진실이 아니다. 게시 스냅샷은 Git 저장소, 정확한 커밋, 내용 목록과 두 표현 해시에 결속되며 클라우드는 수락된 불변 게시 리비전을 소유한다.

식별자별 AI Skill 하나와 한국어 HTML·CSS·JavaScript 표현 하나를 유지한다. 전체 AI 지시 목록을 출처 순서·계층대로 번역하고 정확한 출처·줄 해시를 붙인다. 해시 범위는 의미를 증명하지 않으므로 독립 의미 검토와 권위 증거를 보존한다. 한쪽만 변경되거나 부분·오래됨·순서 변경·중복·요약·오역이 있는 쌍은 미완료이며 완료로 보고하지 않는다.

로컬 실행 전용 증거, 실행 기록, 발신함과 복구는 로컬에 남는다. 필요한 영속 증거는 승인된 클라우드 문서 도구로 업로드한다. 기존 로컬 문서, db.sqlite와 동기화 설정은 목록화·백업·독립 가져오기 검증 전까지 보존한다. 코드 폐기는 데이터 삭제 권한이 아니다. 이 계약은 등록, 설정된 계정, 배포 또는 전체 이관 완료를 주장하지 않는다.

클라우드 문서 어댑터와 이관

권위와 경로

Human이 선택한 Agent Factory 클라우드 MCP 애플리케이션이 새 저장, 불변 리비전 게시, 문서 설정과 검색을 소유한다. 로컬 셸·파일 도구는 Git을 조사하고 승인된 증거를 준비하며 로컬 문서 백엔드나 MCP·공급자 서비스가 되지 않는다. 호출 전에 제공된 스키마를 읽는다. 인증, 테넌트 결속, 권한 또는 역량이 없으면 종속 작업을 중단하고 정직하게 보고한다. 계정 ID나 자격증명을 만들지 않는다.

document_read로 메타데이터·리비전·출처 이력·제한 다운로드를, document_import로 바이트 보존 가져오기와 완전한 명세 패키지를, document_write로 제공된 메타데이터·출처 관계 작업을, document_search로 제한 어휘 검색을, document_index로 선택 리비전 색인을 수행한다. 패키지 목록, 정확한 멤버와 격리된 Human 미리보기는 인증된 서버의 리비전별 전달 경로다. 서버가 반환한 경로와 최신 안내를 사용한다. 존재하지 않는 패키지 멤버 MCP 도구를 추론하거나 임의 객체 저장소 URL을 만들지 않는다.

가져오기와 게시

조사한 증거로 스키마 버전, 정확한 테넌트·문서 식별자, 불변 document_type, 출처 식별자, 수집 맥락, 파일명·MIME, 크기·해시와 예상 리비전을 결속한다. 새 식별자는 예상 리비전 0, 갱신은 정확한 현재 리비전을 쓴다. 응답 확인이 불명확하면 같은 멱등 키와 정확한 요청을 유지한다. 같은 키의 변경된 내용은 충돌하며 새 키도 slug·리비전 충돌을 우회하지 못한다. 충돌을 읽고 조정하되 조용한 덮어쓰기·복원·유형 승격을 하지 않는다.

기본 파일은 바이트가 동일해야 한다. ZIP 경로는 탈출·링크·특수 파일·충돌이 없는 안전한 상대 경로여야 하며 제공된 패키지·바이트 한도를 따른다. 임의 압축 파일을 프로젝트에 풀지 않는다. 출처 목록, 이력과 제약을 보존한다. 형식 변환은 별도 승인된 의미 문서 작업이며 물리 이관이 아니다.

인라인 한도를 넘으면 정확한 가져오기 메타데이터·크기·해시로 document_prepare_upload를 호출한다. 원시 바이트는 이미 확인된 서버의 반환 상대 경로에 필요한 기존 인증과 업로드 역량으로만 전송하며 토큰을 URL에 넣지 않는다. 같은 업로드 ID로 document_finalize_upload를 호출한다. 만료·재시도는 최신 스키마를 읽는다. 전달 불명 시 정확한 메타데이터·의도를 재개하며 커밋 불명 뒤 스테이징을 삭제하지 않는다. 최종화는 게시 전 바이트·쌍·리비전 전제조건을 확인한다.

명세는 AI 루트 하나와 Human 루트 하나, 패키지 상대 상호 메타데이터, Git 저장소·커밋, 내용 목록과 두 표현 해시에 결속된 검토 증거를 포함한 완전한 ZIP 하나로 게시한다. 서버는 불변 바이트를 스테이징하고 다시 읽어 해시를 비교한 후 리비전·현재 포인터·색인·멱등 영수증을 트랜잭션으로 커밋한다. 객체 저장소와 DB는 하나의 트랜잭션이 아니며 실패 후 남은 스테이징은 복구 증거다. 실패 시 이전 게시를 보존한다. 해시 범위와 review_attested는 독립적인 의미 수락이 아니다.

읽기와 검색

클라우드 어휘 검색은 제한·테넌트 범위를 가지며 임베딩과 독립적이다. 발견 후 현재 문서를 읽어 리비전·이력·권위를 조회한다. 검색 결과·색인·브라우저 렌더링은 수락·완전성·의미 진실을 성립시키지 않는다. 바이너리 텍스트 추출 미지원은 명시한다.

Human 패키지 미리보기는 불투명 출처 샌드박스에 격리된다. 검증된 패키지 상대 자산을 사용하며 문서 코드에 동일 출처 애플리케이션 접근, 자격증명 접근이나 임의 네트워크 가져오기를 허용하지 않는다. 원시 멤버 다운로드는 애플리케이션 출처에서 HTML을 실행하지 않는다. 동적 렌더러가 지원되지 않아도 읽을 수 있는 한국어 기본 내용과 로컬 자산을 보존한다.

물리 이관과 복구

초기화·이관은 분류·변환·수락과 구별되는 Document 역량이다. 각 문서의 식별자, documentType, 출처 이력, 권위와 명세 결속을 보존한다. 기존 로컬 직접 패키지와 동기화 설정은 보존할 출처 입력이며 새 소비자 런타임 저장소가 아니다. db.sqlite는 기존 비권위적 투영이며 이관 목록·저널·복구 권위가 아니다.

출처와 목적지를 먼저 목록화하고 독립 백업을 남긴다. 결정적 작업은 식별자·위치·순서 있는 효과·목록과 해시·크기·리비전·권위 참조·충돌·쌍 그룹·사후조건·복구 동작을 폐쇄된 버전별 허용 목록에 결속해야 한다. 실행 직전 현재 상태를 재확인한다. 모델의 원문·코드·SQL·셸 조각이나 스키마 모양 제안은 실행 권한이 아니다. 분류·출처·조정 자문은 unknown 또는 requiresDecision을 남길 수 있다.

오래된 계획, 위험 경로·심볼릭 링크, 충돌, 미지원 버전·역량, 확인 불가능한 쓰기 주체, 부족하거나 과도한 범위, 누락된 출처·권위, 유형 변경, 부분·의미 불일치 쌍은 거부한다. 초기화는 기존 내용을 보존하고 멱등적이다. 게시 전에 스테이징·검사를 수행하며 단일 파일 이름 변경으로 백엔드 간·쌍 원자성을 추론하지 않는다. 원자적 쌍 게시를 보장할 수 없으면 이전 권위와 복구 가능한 스테이징을 보존한다.

전환 전에 가져온 식별자·유형·이력·바이트·쌍·역사를 독립 검증한다. 복사 성공만으로 무결성·수락·전환이 성립하지 않는다. 파괴 효과, 덮어쓰기, 출처 폐기·삭제에는 정확한 Human 권한이 필요하며 코드 폐기는 사용자 데이터 삭제를 허용하지 않는다. 복구는 검증된 상태·저널 증거를 사용하고 안전한 되돌리기가 증명되지 않으면 멱등 재개나 전진 복구를 우선한다. 손상을 숨기려 역사·해시를 바꾸거나 더 새로운 수락 쓰기를 되돌리지 않는다.

책임과 남은 배포 작업

Main은 권위를 확인하고 통합한다. Work는 자가 검증 없이 작성하거나 승인된 결정 작업을 호출한다. 독립 Verification은 증거를 평가하고 실패를 같은 Work에 돌려준다. 결정적 서버 무결성 검사는 이 역할을 대체하지 않는다. Gather는 제한 외부 수집, Tool은 논리 연결 생명주기, Agent는 로컬 exec·loop와 영수증, Workspace는 투영, Convention은 공통 규칙을 소유한다. Skill·Agent 역할을 추가하지 않는다.

클라우드 선택은 수락됐지만 실제 테넌트·계정 ID, 자격증명 권위, 보존·삭제 정책과 미해결 충돌은 여전히 명시적으로 확인해야 한다. 사용 시점에 제공 역량을 확인한다. 이 계약은 마이그레이션 적용, 작업자 등록, 계정 설정, 배포·재시작 또는 1–13단계 완료를 수행·보증하지 않는다. 이전 이관 설계 근거는 run-20260830T135328504819Z-24544fc7과 document-adapter/llm-document-migration 연구 실행 기록에 남으며 현재 클라우드 이관 요청이 그 미해결 백엔드·로컬 관리자 경로를 대체한다.

원본 문서

유형 계약

원본 문서(Original)는 출처에 충실한 증거다. 충실도, 식별자, 출처 이력, 수집 맥락과 기본 또는 출처에 적합한 형식을 보존한다. 원본 문서는 다양한 출처 형식을 사용할 수 있으며 하나의 정식 원본 형식을 강요하지 않는다.

Original은 문서 유형이며 품질·완전성·성숙도·신뢰·권위에 관한 판단이 아니다. 가공 문서나 명세를 만들지 않고 원본으로 남을 수 있다.

관계와 출처 이력

Original -> Processed -> Specification의 개념 순서는 가능한 파생·증거 관계를 나타낼 때만 사용한다. 관계는 없거나 일대다·다대일·다대다일 수 있다. 실제 관계가 있으면 이후 조회에 충분한 출처 식별자·위치·취득과 수집 맥락·변환 연결을 보존한다. 필수 전환·일대일 대응·완전성·자동 승격을 추론하지 않는다.

Gather 경계

Gather는 외부 문서 탐색·가져오기·갱신·미러링을 확인된 목적지로 수행하는 일을 소유한다. Document는 원본 유형 정의와 이미 확인된 원본 대상의 작업을 소유한다. 수집은 출처 자료를 보존하며 주장을 조정하거나 증거를 명세로 승격하지 않는다.

Explorer가 생성·보존한 원본에도 같은 충실도·이력 규칙이 적용된다. Explorer는 제한 Work 작업에 적용하는 Convention 소유 역량이며 공개 Skill이 아니다.

명세 문서

의미 모델

명세 문서(Specification)는 수락·조정된 프로젝트 지식이다. AI Skill 하나와 한국어 Human HTML·CSS·JavaScript 표현 하나가 안정적 식별자 하나 아래 의미 본문 하나를 이룬다. 중요한 출처 이력과 정직한 미해결 상태를 보존한다. 독립 Human 페이지, 여러 Skill의 집합, 무관한 선택 Project Skill 또는 Workspace 탐색은 쌍을 대신하지 못한다.

두 표현은 완전한 주장·결정·요구·관계·범위·출처 순서·계층을 동일하게 보존해야 한다. 모든 의미 편집은 반대쪽 대응 편집을 포함한다. 한쪽만 있거나 누락·오래됨·순서 변경·중복·요약·오역이 있는 쌍은 실패 처리하며 완료로 보고할 수 없다. 해시·시각·상호 메타데이터는 번역 충실도나 수락을 증명하지 않으므로 독립 의미 검토가 필요하다. 조회 자체는 편집 권한이 아니다.

식별자와 작성 소스

Git이 배포 Skill 작성을 소유한다. 플러그인의 여섯 단일 이름 식별자와 skills/<id>/ ↔ docs/specifications/<id>/ 소스 쌍을 보존한다. 저장소의 .codex/에 복제하지 않는다. 일반 소비자 Project Skill은 Human이 확인한 소문자 하이픈 형식 <category>-<title> 식별자를 사용하며 Skill name·쌍 식별자가 일치해야 한다. 기존 식별자를 보존하고 모호한 분류·제목을 만들거나 일괄 이름 변경하지 않는다.

소비자는 자체 .codex/skills/<category>-<title>/에 AI Skill을 설치할 수 있다. 설치 경로, Git 소스 패키지 경로와 게시 클라우드 리비전 위치는 같은 결속 표현의 서로 다른 위치이며 독립 편집 가능한 진실이 아니다. 새 소비자 Human 문서 저장은 클라우드 소유다. 플러그인의 게시 소스 배치를 복제하려 소비자 로컬 문서 백엔드를 만들지 않는다.

패키지 상대 상호 메타데이터를 보존한다. Skill은 metadata.specification-id, human-entry, ai-root를, Human은 agent-factory:specification-id, agent-factory:ai-root, agent-factory:ai-binding-entry를 사용한다. ID와 확인된 위치는 양방향 일치해야 한다. 게시 스냅샷은 Git 저장소·정확한 커밋·파일 목록에 결속되며 소스를 덮어쓰거나 클라우드 편집을 조용히 Git 정본으로 만들지 않는다. 의미 변경 요청은 소유 소스에서 조정하고 새 검토 쌍으로 게시한다.

AI Skill 구조

SKILL.md는 필수 진입점이다. 선택적인 agents/에는 openai.yaml을 포함한 YAML 설정, references/에는 Markdown 참조, assets/에는 재사용 소스·템플릿·이미지·데이터, scripts/에는 필요할 때 소유 실행 동작을 둔다. 실제 내용이 있는 디렉터리만 만든다. Markdown 참조를 assets에, 비YAML 설정을 agents에 넣거나 Skill 하나를 다른 위치로 분할·복제하지 않는다. 클라우드 이관은 로컬 exec·loop와 최소 런타임 의존성을 남기며 새 실행 문서 도메인 서비스를 만들지 않는다.

선택적 references/diagrams.md, roadmap.md, issues.md는 근거 있는 도식, Human 지시 결과·상태와 추적 가능한 문제를 담는다. 도식 소스는 Mermaid 코드 블록을 우선한다. AI는 초안을 만들 수 있지만 우선순위·마감·담당자·수락·이슈 종료·완료·위험 수용을 발명할 수 없다. 검토 승인 자체는 로드맵 작업 완료나 이슈 종료가 아니다. Human 표현에 없는 비공개 추가·모순 지식을 참조에 넣지 않는다.

완전한 한국어 표현

본문·제목·레이블·접근성 문구·설명을 한국어로 작성한다. 번역이 정확도를 낮출 때만 기술 식별자·코드·경로·명령·고유명사·인용을 그대로 유지하며 영어 미완성 틀을 허용하는 예외가 아니다. index.html에서 ./styles.css, ./app.js 및 선택적 로컬 자산으로 직접 읽을 수 있어야 한다. Markdown·JSON은 정식 Human 명세가 아니다.

SKILL.md를 먼저, 다음으로 AI 루트의 모든 나머지 Markdown과 agents/의 YAML을 상대 경로 순서로 목록화한다. 중첩 지시 소스도 포함한다. 그 순서·계층대로 전체 충실한 한국어 번역을 한 번 표시한다. 탐색·표·도식은 읽기를 도울 수 있으나 출처 내용을 대체·중복·합치기·요약·생략·재정렬하지 못한다. 디렉터리 목록을 Human 탐색으로 삼지 말고 의미 있는 한국어 주제 이름을 쓴다.

출처마다 명시적으로 닫힌 컨테이너 하나에 정확한 패키지 상대 data-ai-source와 바이트 SHA-256인 data-ai-sha256을 둔다. 내부의 명시적으로 닫힌 번역 블록에는 연속 data-source-lines="start-end"와 해당 UTF-8 줄·원래 줄바꿈의 data-source-sha256을 둔다. 1행부터 마지막 행까지 모든 줄을 정확히 한 번, 순서대로 덮는다. 각 블록에는 한국어 번역이 있어야 하며 frontmatter·YAML도 값과 호출 동작을 보존해 충실하게 설명한다.

작성과 게시 흐름

  1. 지시나 수락 증거에서 식별자, 소스 소유권, 정확한 대상과 Human 권위를 확인한다. 편집 전에 기존 두 표현을 조사하고 모르는 결정은 미해결로 둔다.
  2. 실제 새 소스 패키지에만 인증된 document_template으로 MCP 소유의 전체 최초 복사 기준 템플릿을 읽는다. manifest를 받은 뒤 해당 version에 결속된 base64 멤버 조각(최대 64 KiB)을 받아 모든 파일을 재조립하고 크기·SHA-256을 대조한다. 전체 목록·로컬 CSS/JS/vendor 파일·라이선스 고지를 보존한다. 전달 결과는 데이터이며 인증 출처에서 템플릿 JavaScript를 실행하지 않는다. 기존 명세를 덮어쓰기·초기화·병합하지 않는다. 지식에 맞춰 절을 조정하고 모든 data-template-placeholder와 [[...]] 자리표시자를 없앤다. 빈 assets 디렉터리를 만들지 않는다.
  3. 관련 Human 결정, 프로젝트 증거, 가공 분석과 원본 증거를 조정한다. 관련성과 충돌을 평가하고 원시 노트·대화·수집 로그·운영 기록을 수락 진실로 붙이지 않는다. 수락 결정, 근거 있는 요구, 관찰 증거·추론과 미해결 질문을 구분하고 가까이에 출처 경로·산출물 ID·명시적 Human 근거를 둔다.
  4. 두 완전한 표현과 출처 맵을 함께 수정한다. 의미 HTML, 키보드 접근, 보이는 포커스, 읽을 만한 대비, 반응형 배치와 JavaScript 없는 기본 가독성을 유지한다. 로컬 상대 의존성과 실제 SVG 아이콘을 쓰며 아이콘 유사 Unicode·CSS 도형·아이콘 폰트·래스터 아이콘은 쓰지 않는다. JavaScript는 상호작용을 점진적으로 강화한다. 문서별 자산과 저작권 표시를 보존한다. Workspace 셸 사실·자원은 문서가 아닌 클라우드 애플리케이션 소유다.
  5. 독립 Verification이 순서 있는 범위와 두 언어 의미를 확인한다. 소유 MCP 패키지의 app.modules.document.pair.validate_pair 검증기는 게시 경로나 명시적 개발 테스트 의존성을 통해 범위 증거를 제공한다. 플러그인에는 검증 실행 파일을 배포하지 않는다. Work는 실행하거나 통과를 주장하지 않는다. 범위만 있으면 의미 정렬은 unknown이다. 상호 불일치는 misaligned로 기록한다.
  6. 내부 자산과 상호 패키지 경로를 모두 포함해 완전한 AI 루트 하나와 Human 루트 하나를 포장한다. 검토된 Git 커밋·목록·검토자·권위 참조·aligned 진술을 두 표현 해시에 결속한다. 각 표현 해시는 모든 루트 상대 파일 경로를 바이트 SHA-256에 대응한 JSON을 키 정렬·간결 구분자·기본 ASCII 이스케이프로 UTF-8 직렬화한 값의 SHA-256이다. 검토자를 발명하거나 오래된 진술을 쓰지 않는다.
  7. adapter.md의 인증된 문서 가져오기·업로드와 정확한 리비전 전제조건을 사용한다. 두 표현을 불변 클라우드 리비전 하나로 게시하며 실패는 이전 수락 권위를 보존한다. 서버 review_attested는 호출자의 검토 증거이며 기계가 증명한 의미 동등성이나 Human 수락이 아니다. Work 작성은 Git 커밋·외부 게시·배포 권한이 아니다.

투영과 경계

Workspace는 수락 리비전을 읽고 격리된 Human 패키지 미리보기를 제공하지만 의미 소유자가 되거나 새 Activity를 추론하거나 누락 Skill을 보충하거나 내용을 승격하지 않는다. 브라우저 탐색은 skills/workspace/references/interface.md를 적용한다. 읽기 전에 AI가 원시 Markdown·JSON을 해석해야 해서는 안 된다. 불투명 출처 미리보기는 부모 애플리케이션 DOM·자격증명·임의 네트워크 가져오기·동일 출처 스크립팅에 의존하지 못한다.

영속 Explorer 증거는 확인된 클라우드 저장소의 원본·가공으로 남고 실행 전용 임시 자료는 관리 로컬 실행에 남는다. Explorer 출력을 자동으로 Project Skill로 승격하지 않는다. 소스 패키지는 작성 입력, 로컬 실행·발신함·복구는 운영 상태이며 수락 클라우드 리비전은 게시 문서 상태를 소유한다. 기존 출처는 백업과 독립 가져오기 검증까지 보존하며 스크립트 삭제가 Human 데이터 삭제를 허용하지 않는다.

skills/document/references/ 파일은 AI Markdown 지시이며 독립 Human 명세가 아니다. 그 형식은 Human 명세의 HTML·CSS·JavaScript를 Markdown으로 대체하도록 허용하지 않는다. AI 지시가 한국어로 작성돼도 전체 쌍에 출처 맵과 한국어 번역을 적용한다.
