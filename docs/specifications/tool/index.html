Agent Factory Tool

진입 계약

Human·Agent가 Playwright·pytest·Office·Google Drive·OneDrive 같은 외부 도구·연결의 통합 제어 계약을 필요로 할 때 쓴다. Tool은 논리 발견·카탈로그 메타데이터·설치와 갱신 및 제거 경로·연결과 인증 생명주기·자격증명 참조·요청과 허용 범위·가용성과 상태·활성 및 비활성 상태·역량 메타데이터를 소유한다.

Tool은 패키지 관리자·플러그인 관리자·MCP 등록부·프로젝트 의존성 매니페스트·자격증명 저장소·실행 런타임의 권위가 되지 않는다. 각 연동의 실제 호스트·플러그인·MCP 서버·프로젝트 매니페스트·명시 선택 공급자를 확인·보존한다. 구현·조사하지 않은 설치·연결·상태 확인·등록부·상태 백엔드를 주장하지 않는다.

자격증명·토큰은 Tool 메타데이터가 아니다. 소유 공급자에 맞는 불투명 참조만 기록하고 저장소·명세·영수증·카탈로그에 비밀을 쓰지 않는다. .agent-factory/tool/을 발명하거나 Tool 등록부·상태 백엔드를 묵시 선택하지 않는다.

Agent는 Work·Verification 역량 결속·실행 권위·영수증을, Convention은 공통 안전·최소 권한·승인을 소유한다. Workspace는 Tool 상태를 표시하거나 승인된 제어를 연결할 수 있지만 생명주기 상태를 소유하지 않는다. Tool은 Workspace Activity를 추가하지 않는다.

Gather는 출처 선택·목적지·제한 읽기 동기화·충실도·식별자·이력·원본 출력을 계속 소유한다. 연결 기반 수집에 필요한 역량·최소 범위·Human 승인 필요성·선택 한도를 선언하면 Tool이 연결을 확인·준비하고 실제 허용 범위를 보고한다. 자체 범위 확대는 금지한다.

클라우드 연결과 로컬 조사

새 공급자 연결·인증 작업은 확인된 인증 클라우드 MCP가 제공하는 도구를 쓴다. agent-factory://integrations/guide, 현재 스키마, references/lifecycle.md를 읽는다. 클라우드는 암호화된 연결 자격증명·연동 설정을 소유하고 Tool은 논리 제어 의미·불투명 참조를 유지한다. 역량·권한·계정·연결이 없으면 미해결·사용 불가로 남는다. 실제 상태를 발명하거나 기존 공급자 스크립트로 대체하지 않는다.

로컬 Git·GitHub CLI·Git LFS·Playwright는 Agent의 기존 셸·파일 도구로 명시 대상·선택 권위를 조사한다. 프로필 참조에 따라 제한 비밀 없는 사실만 수집한다. 로컬 Tool MCP·공급자 서비스를 만들지 않는다. 로컬 Tool adapter 실행 파일은 대체 구현의 독립 검증 후 퇴역했으며 사용자 데이터 삭제 권한을 주지 않는다.

Git Tool 프로필

서로 독립적인 논리 프로필 세 개다. Tool 소유 등록부가 아닌 투영·제어 경로다. 설치·연결·활성·건강을 추론하지 않는다. 지정 권위를 조사한 뒤에만 사실을 보고하며 아니면 적절히 unknown·unavailable을 쓴다.

프로필 ID권위역량 ID
git.cli기본 git 실행 파일, OS 패키지 권위, 선택 저장소·작업 트리git.cli.inspect, git.cli.execute
github.cli기본 gh 실행 파일, OS 패키지 권위, 선택 호스트의 GitHub CLI 인증·설정github.cli.inspect, github.cli.execute
git-lfs.cli기본 git-lfs 실행 파일, OS 패키지 권위, 저장소 Git 설정·훅·속성·LFS 데이터git-lfs.cli.inspect, git-lfs.cli.execute

역량 가용성은 프로필별이다. 조사 가능성이 실행 권한을 뜻하지 않고 한 프로필 준비가 다른 프로필 준비를 증명하지 않는다. Tool은 백엔드 생성·상태 저장 없이 안정 ID를 투영할 수 있다.

공통 발견과 생명주기 경계

버전 관찰 전 정확한 실행 파일을 확인한다. 설치·갱신·제거 경로 전에 실제 OS 패키지 관리자·설치자를 확인하며 실행 파일 소유 패키지를 가정하지 않는다. 실행 파일·패키지 가용성·버전·저장소 설정·인증·상태는 관찰 시각과 함께 별도 사실로 유지한다.

설치·갱신·제거·로그인·로그아웃·저장소 쓰기·원격 작업·정리는 상태 변경이다. 경로 연결 전에 정확한 실행 파일·패키지, 해당 저장소·작업 트리·호스트·계정, 예상 효과·복구 제약·명시 Human 승인을 확인한다. 공급자 출력은 권위를 유지하며 Tool 준비는 실행 권한이 아니다.

git.cli

조사한 실행 파일·버전, 확인 가능한 패키지 권위, 정확한 선택 저장소·작업 트리만 투영한다. 저장소 대상이 없어도 Git 실행 파일은 사용 가능할 수 있다. 여러 작업 트리가 있을 수 있으므로 저장소·공통 Git 디렉터리·작업 트리 루트·브랜치·detached HEAD를 하나로 합치지 않는다.

읽기 발견은 실행 파일 해석·git --version 뒤 명시 대상에 비변경 질의로 저장소·작업 트리를 확인할 수 있다. 저장소 없음·질의 미지원·패키지 권위 미해결은 Git 자체가 건강하지 않다는 증거가 아니다.

저장소 생성·clone, refs·인덱스·작업 파일 변경, 설정 편집, 작업 트리·remote 추가와 제거, fetch·pull·push·commit·merge·rebase·reset·restore 등 저장소 작업은 제한 Work·도메인 실행이다. Tool 생명주기 관리가 아니다. Agent가 git.cli.execute를 정확한 작업·대상·권위·영수증에 결속해야 한다.

github.cli

명시 GitHub 호스트에 대해 조사한 실행 파일·버전과 공급자 인증 상태만 투영한다. 계정 ID·활성 계정·안전하게 보고된 인증 방법·허용 범위를 포함한다. 토큰·자격증명·비밀 출력은 포착·저장하지 않는다. 특히 상태 확인에 토큰 출력 명령을 쓰지 않는다.

실행 파일 가용성과 인증은 독립적이다. 설치 gh가 미인증일 수 있고 한 호스트 인증은 다른 호스트를 설명하지 않는다. 알 수 없음·만료·부족·과도 범위를 명시하며 요청·실제 허용을 구분한다.

로그인·로그아웃·계정 전환·호스트 변경·범위 갱신은 명시 Human 승인을 받고 GitHub CLI 자체 인증·설정 권위로 연결한다. Tool은 토큰·대체 인증 기록을 저장하지 않는다. PR·이슈·릴리스·저장소·워크플로·API 작업은 github.cli.execute의 제한 도메인 실행이며 생명주기가 아니다.

git-lfs.cli

실행 파일 해석·git-lfs 버전, 패키지 권위가 보고하는 설치 가능성, 별도 조사한 저장소 활성·설정을 투영한다. 실행 파일 가용성이 저장소 LFS 활성화를 증명하지 않는다. 활성은 Git 설정·훅, 추적 정책은 속성으로 표현될 수 있으며 서로에서 추론하지 않는다.

git lfs install, uninstall, track, untrack, migrate, prune은 상태 메타데이터 조회가 아닌 저장소·전역 설정·역사·속성·훅·로컬 데이터 변경이다. 정확한 대상·영향 평가·복구 영향·필요 Human 권한 없이는 실행하지 않는다. 원격 전송·다른 LFS 내용 작업도 git-lfs.cli.execute의 제한 실행이다.

저장소 설정을 원격 LFS 접근과 동일시하지 않는다. 인증은 Git·자격증명 보조자·호스팅 공급자·다른 확인 권위가 매개할 수 있다. 그 권위를 유지하고 Tool 메타데이터에 자격증명을 복사하지 않는다.

로컬 조사 경로

Agent의 기존 셸·파일 도구를 쓰며 새 로컬 Tool MCP·공급자 서비스를 만들지 않는다. 기존 로컬 Tool adapter는 퇴역했다. 실행 파일·명시 프로젝트를 확인한 뒤 제한 버전·비변경 저장소 사실을 조사한다. 작업 트리 루트·Git 디렉터리·공통 디렉터리·브랜치·detached 상태를 분리한다.

명시 호스트 하나에는 지원될 때 비밀 없는 gh auth status --hostname HOST --json hosts를 쓰고 제한 계정·범위 사실만 보존하며 토큰 출력을 남기지 않는다. 실행 파일 가용성·구조화 조회 지원·인증은 별개다. 필드 미지원·응답 해석 불가면 인증은 unknown이다. 지원 응답만 available·unavailable 인증을 성립시킨다. LFS 활성·원격 접근은 별도 관찰 없으면 unknown이다.

실제 패키지·인증·저장소·원격 변경은 소유 권위에 남고 승인된 대상·효과가 필요하다. 발견은 수행 권한이 아니다. 필요한 비밀 없는 조사 증거만 인증 Document 도구로 결속 클라우드 대상에 업로드한다.

Tool 생명주기 계약

생명주기 전에 권위 확인

상태를 설명·변경하기 전에 권위 공급자를 식별한다. 호스트 기본 도구·설치 플러그인·MCP 서버·프로젝트 패키지 매니페스트·명시 선택 공급자는 자체 설치·버전·연결·런타임 상태의 권위를 유지한다. Tool은 통합 논리 제어 계약이며 대체 등록부·패키지 관리자가 아니다.

요청 작업을 제공하는 백엔드가 없으면 미해결·사용 불가로 보고한다. 논리 모델을 구현된 것처럼 보이게 하려고 등록부·상태 서비스·자격증명 저장소·.agent-factory/tool/을 만들지 않는다.

논리 항목

Tool 항목은 조사되거나 공급자가 보고한 사실만 투영한다.

  • 안정적인 공급자·도구 식별자와 표시 메타데이터.
  • 권위 종류·불투명 참조.
  • 역량 ID와 제한 입출력 메타데이터.
  • 권위가 제공하는 설치·활성 상태.
  • 비밀 없는 연결 ID.
  • 자격증명·토큰 아닌 불투명 참조.
  • 요청 범위·실제 허용 범위.
  • 가용성·상태·관찰 시각·정직한 알 수 없음.
  • 버전·갱신 사실·지원 생명주기 작업.

알 수 없음·미지원·오래됨·사용 불가는 별개다. 설치에서 건강 상태, 설정에서 연결, 요청 범위에서 허용 범위를 추론하지 않는다.

생명주기 작업

발견·설치·갱신·제거·연결·해제·활성·비활성·상태 작업은 권위 공급자로 연결한다. 상태 변경 전에 정확한 대상·예상 효과·권위·필요 Human 승인을 확인한다. 공급자의 확인·복구 계약을 보존한다. Tool 연동 제거는 별도 정확한 Human 승인 없이 외부 데이터·자격증명 삭제를 뜻하지 않는다.

선언 역량의 최소 범위를 요청하고 요청·허용을 따로 표시한다. 공급자가 더 적거나 많이 허용하면 차이를 밝히고 승인 경계를 넘으면 중단한다. Tool은 자동 확대하지 않는다.

Agent 결속

Tool 준비 상태는 실행 권한이 아니다. Agent는 특정 Work·Verification 작업에 역량을 결속하고 실행 권위·영수증을 제공한다. Tool은 역량·상태를 보고할 수 있지만 작업 발송·결과 주장은 하지 않는다.

로컬 조사는 기존 Agent 셸·파일 도구를 사용하고 프로필의 정확한 권위를 보존한다. 클라우드 연결은 인증 서버의 도구·스키마를 쓴다. 경로, performed: false 또는 설정 항목은 실행·승인·준비 증거가 아니다. Agent 실행 결속은 별도의 --capability-binding-file이며 Tool은 그 실행 기록을 만들지 않는다.

Gather 연결 협약

연결 기반 수집에 Gather가 제공하는 내용:

  • 연결 역량·출처 식별자.
  • 최소 권한 범위.
  • Human 승인·관리자 동의 필요성.
  • 파일·폴더·드라이브·재귀·시간·개수 등 선택 한도.
  • 확인 목적지·읽기 전용 동기화 의도.

Tool은 확인한 공급자 권위·연결 ID·실제 허용 범위·가용성과 상태·필요 시 불투명 자격증명 참조를 반환한다. Gather는 자체 충실도·식별자·이력·원본 계약 아래 제한 수집을 수행·기록한다.

인증 클라우드 생명주기

agent-factory://integrations/guide와 현재 스키마를 읽는다. 기존 승인 조직·Workspace·공급자 연결·계정을 확인한다. 연결 생성에는 기존 서버 연결 API를 쓰며 도구 이름을 발명하지 않는다. integration_inspect는 명시적 실시간 요청 외에는 캐시 메타데이터를 반환한다. 상태·범위 조회 지원·요청 범위·관찰 허용·관찰 시각·오래됨을 구분한다. 권한 열거 미지원·일시 실패는 미인증이 아닌 알 수 없음이다.

명시 승인 공급자·계정·범위에 integration_oauth_begin을 쓰고 서버 설정 콜백 또는 제공된 integration_oauth_complete 흐름을 따른다. 일회용 상태·시작 사용자·테넌트 결속을 보존한다. 클라우드는 클라이언트 비밀·교환·암호화 갱신 자격증명을 소유한다. 토큰 공급자는 보호된 Human 비밀 입력을 사용한다. integration_token_set은 저장만 하며 실제 접근을 증명하지 않고 토큰 도구 인수는 클라이언트 기록에 남을 수 있다. Agent에게 프롬프트·셸 인수로 비밀을 전달하게 하지 않는다. 자격증명 저장소를 발명하거나 계정·범위를 조용히 바꾸지 않는다.

연결 준비는 수집 승인이 아니다. Gather는 역량 결속 뒤 자체 불변 제한 클라우드 수집을 생성·시작한다. 새 연결·수집 설정은 클라우드 소유이며 기존 로컬 OAuth·장치 코드·토큰 캐시는 이관 입력이다. 로컬 공급자·Tool 실행 파일은 대체 구현의 독립 검증 후 퇴역했다. 이 계약에서 배포 등록·설정 자격증명·동의·실제 공급자 접근을 추론하지 않는다.

Playwright Tool 프로필

안정 논리 프로필 ID는 playwright.browser, 역량 ID는 playwright.browser.inspect·playwright.browser.execute다. 이는 투영·제어 경로이며 Tool 소유 등록부·런타임이 아니다. 설치·활성·호환·건강을 추론하지 않는다.

권위와 관찰

Playwright를 설치 여부 하나로 합치지 말고 각 권위 계층을 보존한다.

  • Node·Python 등 지원 바인딩의 선택 프로젝트 언어·패키지 매니페스트와 잠금 파일은 의존성 선언·해석 의도를 소유한다.
  • 확인된 Playwright 패키지·CLI는 자체 설치 버전을 보고한다.
  • 선택 공급자는 브라우저 바이너리·캐시 위치를 소유하고 브라우저 식별자·리비전을 보고한다.
  • OS·패키지 권위는 시스템 의존성을 소유한다.
  • 호스트 기본 브라우저 역량·플러그인·MCP 서버를 권위로 선택할 수도 있으며 프로젝트 Playwright 패키지와 대응할 필요가 없다.

호스트·플러그인·MCP 브라우저 역량이 있다는 이유로 프로젝트 의존성을 추가·중복하지 않는다. 반대로 공급자 증거·명시 결속 결정 없이 그 역량이 프로젝트 의존성을 만족한다고 하지 않는다.

패키지·CLI 해석, 브라우저 실행 파일 존재, 공급자 호환 보고를 따로 관찰한다. 패키지 존재는 브라우저 존재·호환을, 브라우저 존재는 시스템 의존성·샌드박스·런타임 권한 준비를 증명하지 않는다. 관찰 시각을 기록하고 unknown·unavailable·stale을 구분한다. 설치만으로 건강 결과가 되지 않는다.

생명주기 변경 경계

playwright install, 브라우저 다운로드·갱신·제거, playwright install-deps 및 동등 시스템 패키지 변경은 상태 변경이다. 연결 전에 다음을 확인·제시한다.

  • 정확한 프로젝트·언어 런타임·패키지와 CLI·브라우저 이름과 리비전·캐시와 설치 대상·시스템 대상.
  • 관련 패키지 관리자·Playwright 공급자·OS 패키지 권위.
  • 예상 다운로드·디스크 사용·공유 캐시 영향·권한 및 시스템 패키지 효과·호환 영향·복구 경로.
  • 그 정확한 대상·효과를 덮는 Human 권한.

광범위 캐시 삭제를 갱신·제거·수리·복구 지름길로 쓰지 않는다. 무관한 브라우저 리비전·프로젝트·런타임·공유 캐시·시스템 패키지를 바꾸지 않는다. 공급자 출력은 권위를 유지하며 선택 권위가 작업을 제공하지 않으면 미해결·사용 불가로 보고한다.

Agent 실행과 외부 권위

페이지 이동·클릭·폼 입력과 제출·업로드·다운로드·스크린샷·trace·영상·Playwright 테스트는 playwright.browser.execute의 제한 실행이며 발견·건강·생명주기 작업이 아니다. 준비는 실행 권한이 아니다. Agent는 정확한 작업·브라우저와 런타임 대상·사이트와 애플리케이션 권위·허용 효과·영수증을 결속한다.

브라우저 샌드박스·권한 경계를 지킨다. 페이지·파일·장치·클립보드·알림·다운로드·외부 서비스 접근 기술 능력은 권한이 아니다. 외부 웹 작업은 제출·구매·게시·삭제 등 가시 효과의 확인 요구를 포함해 자체 Human·계정·서비스 권위를 유지한다.

쿠키·storageState·세션·토큰·비밀번호·클라이언트 인증서·프록시 자격증명은 비밀이다. 스크린샷·trace·영상·다운로드·테스트 산출물도 비밀·민감 정보를 담을 수 있다. Tool 메타데이터·저장소·영수증·카탈로그에 저장·노출하지 않는다. 생성·보관 전 정확한 대상·내용 위험·보존과 가림 정책·접근 경계·폐기 동작을 확인한다.

이 프로필은 구체 등록부·건강 서비스·생명주기 백엔드·브라우저 캐시·자격증명 저장소를 정의하지 않는다. 매니페스트·패키지 관리자·Playwright 공급자·OS·호스트·플러그인·MCP 서버는 제공 사실·작업의 권위를 유지한다.

로컬 조사 경로

로컬 MCP·공급자 서비스 없이 기존 Agent 셸·파일 도구로 명시 프로젝트·권위를 조사한다. 기존 로컬 Tool adapter는 퇴역했다. 인식한 매니페스트·잠금 파일과 확인 가능한 로컬·PATH CLI 버전을 조사한다. 건강을 주장하려 브라우저를 시작하지 않는다. 바이너리·시스템 의존성·호환·권한은 공급자 보고 없으면 unknown이다.

명시 플러그인·MCP·호스트 역량은 프로젝트 패키지로 대체하지 않고 자체 권위·참조를 유지한다. 생명주기 변경은 정확한 승인 범위 안에서 그 소유자로만 연결한다. 필요한 비밀 없는 증거는 클라우드 Document로 업로드하고 민감 산출물 처리는 전송 전에 확인한다. 역량 누락은 정직하게 실패하며 조사의 부작용으로 브라우저 다운로드·패키지 변경·캐시 정리를 하지 않는다.
