## Quality bar

- 가능한 한 1차·공식 출처를 사용하고, 핵심 범주마다 복수 출처로 교차 확인한다.
- 각 링크는 실제로 열어 해당 주장을 지지하는지 확인한다.
- 날짜 없는 자료와 계속 갱신되는 문서는 그 성격을 표시한다.
- 제품 가격/모델/기능/벤치마크 순위처럼 빠르게 변하는 내용은 기준일과 출처를 함께 표시한다.

- 제품 변경이나 Specification/Project Skill 승격은 하지 않는다.
- 테스트나 검증 명령은 실행하지 않는다. 웹 근거 조사와 문서 작성만 수행한다.
