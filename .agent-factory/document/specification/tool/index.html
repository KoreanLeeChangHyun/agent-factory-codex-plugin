01

논리적 생명주기

Tool은 설치·연결·상태를 설명하고 올바른 소유자에게 작업을 routing합니다.

Discovercapability와 provider
Prepareinstall·connection 경로
Observescope·health·enablement
Retireowner가 수행하는 제거

현재 adapter에서 상태 변경 verb는 실행이 아니라 provider-route-required와 performed: false를 반환합니다. 이 결과는 승인, 준비 완료, provider 지원의 증거가 아닙니다.

02

권위와 비밀의 경계

Tool은 credential 자체를 저장하지 않고 provider 권위를 그대로 보존합니다.

Tool이 다루는 것원래 소유자가 관리하는 것
capability metadata, requested/granted scope, 관찰된 healthcredential, token, 설치·제거·인증의 실제 상태
lifecycle routing과 명시적 authority referencehost, plugin, MCP server, project manifest

Tool readiness는 실행 권한이 아닙니다. Agent가 별도의 strict binding으로 capability, authority, route, exact target, 허용 effect/scope와 approval reference를 run에 연결합니다.

03

상태 없는 조사 adapter

skills/tool/scripts/tool.py는 저장소나 registry를 만들지 않고 한 번의 JSON 관찰 결과를 냅니다.

읽기 전용

discover, inspect, health는 기존 directory와 provider가 보고하는 제한된 사실만 조사합니다.

기계 판독 가능

profile ID, capability IDs, authority kind/reference, exact target, 사실, route, 관찰 시각, 비밀 미저장 여부를 구분합니다.

정직한 상태

plugin, MCP, host adapter가 없으면 project package로 대체하지 않고 unknown을 유지합니다.

Adapter는 install, update, remove, connect, authenticate, enable, disable, browser 실행 또는 domain task를 수행하지 않습니다. .agent-factory/tool/도 만들지 않습니다.

04

Git·Playwright profile

Profile구현된 관찰추론하지 않는 상태
git.cliexecutable/version, worktree, Git/common directory, branch·detached HEADrepository mutation 권한
github.cli명시 hostname의 비밀 없는 gh auth status --hostname HOST --json hosts 결과와 inspectionSupport다른 hostname, token, 실행 권한
git-lfs.cliexecutable/version, repository identityactivation, remote access
playwright.browsermanifest/lockfile, resolved CLI/versionbrowser·system dependency·sandbox·permission readiness

GitHub CLI executable availability, structured inspection 지원, authentication state는 서로 다른 관찰입니다. Provider-supported non-secret --json hosts 결과는 bounded hosts/account projection으로 제한합니다. Older CLI가 이 interface를 genuinely unsupported하면 authentication은 unknown이며, malformed response도 unknown입니다. 지원되는 구조화 응답만 실제 인증됨을 available, 실제 미인증을 unavailable로 보고합니다.

Playwright health 조사는 browser를 시작하지 않습니다. 명시한 plugin, MCP 또는 host capability는 해당 authority adapter가 없으면 unknown으로 남습니다.
