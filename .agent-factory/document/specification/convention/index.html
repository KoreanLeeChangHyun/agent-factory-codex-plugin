01

코어 책임 지도

Convention은 실행자가 아니라 모든 Skill에 적용되는 공통 의미와 제약의 소유자입니다.

문서 모델

Original, Processed, Specification의 느슨한 관계

역량 경계

Explorer와 Interview는 public Skill이 아닌 적용 역량

공통 안전

최소 권한, 승인, provenance, 정직한 미해결 상태

공유 로컬 카탈로그는 Agent 구현 소유이며 Workspace는 Agent-provided read-only 결과를 표시할 수 있을 뿐 직접 명령을 실행하지 않습니다. Convention은 이 cross-cutting 소유 규칙만 유지하고 상세 명령과 schema·검색·복구 계약은 Agent Specification에 둡니다.

03

검증 뒤 커밋은 Main이 직접 수행합니다

독립 Verification pass 또는 현재 Work 완료 뒤 근거 있는 Human skip이 적용된 다음, Main이 별도 commit Work turn 없이 승인된 ordinary Git commit을 결과 통합·게시로 직접 빠르게 수행합니다.

graph 보존

커밋은 Work·Verification·새 Agent role·새 graph node가 아닙니다. Work와 Verification은 커밋하지 않으며 Main → Work → Verification 흐름은 유지됩니다.

exact-path staging

Main은 latest Work result·receipt, Verification pass receipt 또는 Human-skip evidence, 현재 status·diff를 확인해 해당 결과에 결속된 정확한 경로만 stage합니다. 관련 없는 dirty·untracked·generated·runtime 변경은 제외하고 Specification pair는 완전하게 유지합니다.

권한 경계

ordinary commit 권한에서 push, amend, force, history rewrite, reset, restore, delete 또는 다른 repository mutation을 추론하지 않습니다. 정확한 안전 staging이 불가능하면 범위를 넓히지 않고 obstruction을 보고합니다.

03

영향받은 domain의 최소 테스트

구현, 유지보수 또는 Verification에서는 소유 component와 변경된 contract에 해당하는 가장 작은 focused test set을 선택합니다.

소유 경계에 맞춤

소유 프로젝트의 runner·framework·component 경계·test 구성을 따르며 특정 command나 directory layout을 보편 규칙으로 만들지 않습니다.

확대 조건

focused evidence에서 cross-domain 영향을 보일 때 또는 Human이 더 넓은 범위를 명시적으로 요청할 때만 넓힙니다. repository-wide full suite는 Human이 명시적으로 요청한 경우에만 실행합니다.

독립 Verification

focused 범위 규칙은 독립적인 Verification role을 합치거나 대체하거나 생략하지 않습니다. Verification도 같은 확대 조건 아래 가장 작은 관련 범위를 독립적으로 확인합니다.

04

명시되지 않은 결정은 반드시 묻고 기다립니다

요구사항, 선택, 범위, 권한, 인수 기준은 Human이 직접 말했거나 이미 수락된 Specification이 모호함 없이 정한 경우에만 명시적인 것으로 취급합니다.

추론하지 않음

필수 부분이 명시되지 않았다면 추론, 발명, 묵시적 기본값 적용을 하지 않고 가정을 결정처럼 제시하지 않습니다. 침묵, 모호함, 관행, 선례, 그럴듯한 선호, 이의 없음은 명시적 결정이 아닙니다.

사실과 선택을 구분

repository 조사와 evidence gathering은 관찰 가능한 사실을 밝힐 수 있지만 빠진 Human 결정을 만들어내지 못합니다.

역할 경계

Main만 Human에게 질문하고 답을 기다립니다. Work와 Verification은 미해결 질문을 Main에 보고하고 영향을 받는 결정을 통과하지 않습니다. Explorer는 사실 증거를 수집할 수 있지만 Human-owned choice로 바꾸거나 Human을 interview·impersonate하지 않으며, Interview는 Main만 수행합니다.

Main, Work, Verification, Explorer, Interview 전체에 적용합니다. 이 규칙은 새 Agent role, public Skill, capability를 만들지 않으며 기존 안전, 권한, Specification pair, managed graph 계약도 약화하지 않습니다.
