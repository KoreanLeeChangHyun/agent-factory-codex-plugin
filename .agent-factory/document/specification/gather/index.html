Agent Factory Gather

진입 계약

분산된 자료를 찾아 가져오거나 갱신·미러링하여 원본 문서로 보존한다. 원래 형식 또는 출처에 적합한 바이트, 출처 식별자, 출처 이력, 수집 맥락과 확인된 목적지를 유지한다. 수집 증거는 조정·수락된 명세 지식이 아니다. 공급자 작업은 읽기 전용으로 유지하며 제한된 수집을 완전한 미러라고 하지 않는다.

Gather는 선택, 목적지, 한도, 동기화와 원본 출력을 소유한다. Tool은 논리적인 연결·인증 생명주기를 소유하고 요청 범위와 관찰된 실제 허용 범위를 구분해 보고한다. Agent는 정확한 역량, 권위, 대상과 허용 효과를 실행에 결속한다. 수집 전에 관리 참조와 선택한 공급자 참조를 끝까지 읽는다.

실행 경계

새 수집 작업은 확인되고 인증된 Agent Factory 클라우드 MCP 애플리케이션이 제공하는 도구를 사용한다. 호출 전에 agent-factory://integrations/guide 및 최신 도구 스키마를 읽는다. 도구, 연결, 권한 또는 공급자 설정이 없으면 사용 불가나 미해결 상태로 정직하게 보고한다. 기존 로컬 스크립트를 호출하거나 다른 계정을 선택해 우회하지 않는다.

클라우드는 수집 설정과 암호화된 연결 자격증명을 소유한다. 프로젝트에 새 document/sync.json, 로컬 출처 미러, 토큰 캐시나 로컬 MCP·공급자 서비스를 만들지 않는다. 로컬 공급자·sync 실행 파일, 스키마와 의존성 매니페스트는 클라우드 대체 구현의 독립 검증 후 퇴역했다. 기존 출처 데이터는 이관 입력으로 남는다. 별도로 승인된 데이터 폐기 전에 목록화·백업·가져오기 검증을 수행하며, 코드 퇴역은 Human 데이터 삭제 권한이 아니다. 계약 작성만으로 실제 연결, 등록, 배포 또는 이관 완료가 성립하지 않는다.

Discord 수집

먼저 gather-management.md와 인증된 서버의 연동 안내·스키마를 읽는다. Tool이 확인한 연결로 서버 수집 도구를 사용한다. 이 참조는 출처 의미를 정의하며 로컬 공급자 명령을 정의하지 않는다.

선택과 충실도

channel_id, 선택적으로 before 또는 after 중 하나, 한도와 첨부 의도를 지정한다. 봇은 VIEW_CHANNEL과 READ_MESSAGE_HISTORY가 필요하며 특권 메시지 내용 인텐트 때문에 보이는 내용이 제한될 수 있다. 빈 내용은 전체 접근 증거가 아니다. 메시지 API 증거와 첨부 원본 바이트를 보존한다. 서명된 첨부·프록시 URL은 만료되며 저장 증거에서 가린다. 메시지 전송·편집·반응·삭제를 하지 않는다.

연결과 결과

Tool을 통해 서버가 제공하는 인증 경로를 사용한다. 자격증명은 클라우드 자격증명 권위에 남으며 프롬프트·명령 인수·저장소 파일·영수증·출처 메타데이터에 토큰을 넣지 않는다. 요청 범위, 관찰된 허용 범위, 계정 상태, 선택 접근성과 오래됨·알 수 없음 상태를 구분한다. 역량이나 권한이 없으면 로컬 스크립트로 우회하지 않고 종속 수집을 중단한다.

부분 결과, 변환과 범위 제약을 포함하여 클라우드 수집 상태와 저장 결과를 조회한다. 재시도에도 수집·실행·출처 식별자를 보존한다. 취소는 증거를 유지한다. 새 로컬 동기화 설정과 공급자 서비스는 이 계약 밖이며 로컬 공급자 실행 파일은 클라우드 대체 구현의 독립 검증 후 퇴역했다.

클라우드 Gather 관리

권위와 범위 확인

선택된 인증 클라우드 MCP 연결을 사용하고 agent-factory://integrations/guide 및 제공된 스키마를 읽는다. 개발 체크아웃의 구현 안내는 ../mcp/docs/cloud-integrations.md이며 설치 런타임 경로가 아닌 소스 위치다. 기존 권위에서 조직, Workspace, 공급자 계정·연결, 선택, 재귀 여부, 항목·페이지·바이트 한도, 첨부 의도와 필요한 읽기 범위를 확인한다. ID를 만들거나 동의를 확대하거나 요청 범위에서 실제 허용 범위를 추론하지 않는다. 연결 준비는 Tool이 담당하며 연결·인증이 없으면 생명주기 참조를 적용한다.

연결은 계정과 서버에서 암호화한 자격증명을 식별한다. 수집은 비어 있지 않은 이름, 변경 불가능한 제한 선택과 Workspace 원본 목적지를 별도로 고정한다. 여러 수집이 같은 연결을 쓸 수 있다. 선택 변경에는 새 수집이 필요하며 조용히 수정하거나 재시도 범위를 넓히지 않는다. 로컬 목적지, 임의 다운로드 URL이나 공급자 커서는 수집 입력이 아니다.

수집과 조회

  1. integration_inspect(connection_id, live=false)는 알려진 상태를 읽는다. 실시간 조회는 별도 공급자 호출이며 계정 조회 성공이 모든 출처 접근을 증명하지 않는다.
  2. collection_create(request)는 외부 입출력 없이 제한된 선택을 저장한다.
  3. collection_start(collection_id, request_key)는 승인된 수집을 대기열에 넣는다. 영속 키와 실행 식별자를 보존하며 정확한 재시도 의미는 서버 스키마를 따른다.
  4. collection_status(run_id)는 진행 상태를, collection_results(run_id)는 저장된 문서 ID·리비전·해시·제약을 보고한다. 실패·취소 후에도 결과를 조회한다.
  5. collection_cancel(run_id)는 취소를 요청한다. 저장된 원본은 남으며 진행 중 저장은 끝날 수 있다.

항목 수에는 방문한 폴더·블록 등 조사한 항목이 포함된다. 페이지, 메타데이터, 첨부 및 재시도 응답은 공유 한도를 소비한다. 공급자 자료를 다 읽기 전에 한도에 도달하면 bounded이며 완료가 아니다. 새 요청 키는 같은 한도로 원래 선택을 다시 훑으며 한도를 넘는 후속 수집이 아니다. 서버 작업자가 체크포인트, 자격증명 갱신, 제한 재시도와 취소를 소유한다. 권한 부족, 만료된 커서나 전달 불명 상태에서는 식별자와 증거를 보존하고 선택을 조용히 다시 시작하거나 확대하지 않는다.

충실도와 복구

안정적인 출처 단위 하나는 수집별 원본 하나에 대응하며 겹치는 수집은 각 선택 이력을 보존한다. 공급자, 연결, 수집, 출처 식별자, 선택, 출처 메타데이터, 실행, 취득 시각과 제약을 기록한다. 외부 출처에 문서 파생 관계를 만들어 붙이지 않는다. 공급자 내보내기는 변환임을 명시한다.

원래 바이트를 보존한다. 여러 부분으로 된 증거나 저장소가 지원하지 않는 MIME은 변경하지 않은 산출물과 파일명·MIME·해시 목록을 담은 결정적 ZIP으로 포장할 수 있다. 이는 포장이며 형식 변환이 아니다. 빈 출처 바이트도 증거다. 서명 URL과 자격증명을 게시 출처 이력에 넣지 않는다. 일반 비밀 없는 출처 URL과 의미 있는 쿼리 매개변수는 보존한다. 안전한 가져오기, 응답 한도, 불변 리비전과 재시도 체크포인트는 클라우드 도구가 소유하며 대체 로컬 공급자로 사용자 입력 임의 URL을 가져오지 않는다.

새 설정·저장·동기화는 클라우드 소유다. 기존 로컬 sync.json, 출처 모음과 인증 캐시는 새 작업 경로가 아닌 이관 입력이다. 독립적으로 보관한 백업과 검증된 가져오기가 있을 때까지 유지하며 삭제에는 별도 Human 권한이 필요하다. 설정이나 영수증만으로 전체 출처 범위, 실제 인증, 배포된 작업자 등록 또는 전환 완료를 주장하지 않는다.
