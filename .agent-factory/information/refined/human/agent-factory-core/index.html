가공문서

논리적으로 저장소와 독립적인 문서 유형이며, 현재 로컬 기본 어댑터의 활성 문서는 Markdown(.md)입니다.

  • 가설·연구·인터뷰 결과
  • legacy-inquery/는 활성 대상이나 형식 선례가 아님
03

스펙 문서

Human이 수락하고 조정한 프로젝트 지식이며 provenance와 honest unresolved state를 명시적으로 다룹니다.

  • 요구사항·제약·규범적 프로젝트 모델
  • 한국어 Human 표현과 AI-facing Skill
  • 두 표현의 필수 의미 동기화

Original -> Processed -> Specification은 느슨한 개념적 순서입니다. 화살표는 가능한 derivation 또는 evidence 관계만 표현하며 필수 pipeline, state machine, required transition, 일대일 매핑, completeness claim, automatic promotion이 아닙니다. 문서는 한 유형에만 남을 수 있고 관계가 없거나 일대다·다대일·다대다일 수 있습니다. 실제 관계가 있으면 provenance를 보존합니다. Refined는 네 번째 활성 유형이 아니며 세 활성 유형 이름을 결합하지 않습니다.

03

핵심 역량과 책임

역량주요 입력생성 또는 관리 정보책임 경계
GatherGoogle Drive, OneDrive, Slack, Notion, Discord 등 분산 출처원본출처 충실성과 provenance를 보존해 프로젝트에 필요한 정보를 동기화합니다. 내용을 조정하거나 스펙 진실로 승격하지 않습니다.
Explorer웹, 코드, 문서, 원본과 가공 정보원본 가공분석하고 조사하며 탐색합니다. 원래 자료와 변환 결과를 만들 수 있지만 스펙 문서의 수락·조정 주체는 아닙니다.
InterviewHuman의 지식과 질문가공Main Agent가 현재 대화에서 적응형 인터뷰를 수행합니다. 필요한 배경 조사는 Work가 Explorer 역량을 적용해 수행하고 대화를 재개하며, Explorer는 Human을 사칭하거나 인터뷰하지 않습니다.
Document문서와 근거가 있는 Human 결정원본 가공 스펙세 유형을 정의하고 선택적 provenance 관계를 보존하며 모든 스펙 문서의 Human·AI 표현을 함께 유지합니다.
ConventionHuman이 정한 작업 제약전 단계 통제AI가 따라야 할 제약을 기록하는 약한 하네스로 생명주기 전체에 적용됩니다.
Agent역할, 권한, 맥락, 도구, 상태전 단계 실행다섯 공학 계층을 통합해 생명주기 전체의 AI Agent 실행을 담당합니다.
WorkspaceAgents, 문서, 프로젝트 뷰Human 관제탑각 소유자의 상태와 권한을 대체하지 않고 Human이 탐색하고 관리할 수 있는 통합 제어 표면을 제공합니다.

역량과 public Skill은 같은 분류가 아닙니다. 핵심 역량은 Workspace를 포함한 일곱 개이며 public distributed Skill은 agent, convention, gather, document, workspace 다섯 개입니다. Explorer와 Interview의 지속적 의미·권한 경계는 Convention이 소유하고, Agent의 Work와 Main이 각각 적용합니다.

Workspace는 VS Code 형태의 세 영역을 통해 Agent, 문서, 프로젝트 뷰를 한곳에서 탐색하고 관리하게 합니다.

작업 영역

재사용 원본

skills/workspace/assets/workspace.sh

프로젝트 설치본

<project-root>/workspace.sh

copy-once 경계: 루트의 workspace.sh가 이미 존재하면 초기화는 그대로 보존합니다. 이 규칙은 force를 사용해도 바뀌지 않으며, 설치본은 symlink가 아닌 일반 프로젝트 파일입니다.

서로 다른 두 Explorer 위치

임시 근거 저장소

.agent-factory/explorer/

Work가 Explorer 역량을 적용하며 만드는 임시 evidence workspace입니다.

읽기 전용 Activity 투영

.agent-factory/workspace/explorer/

프로젝트 트리와 임시 근거 트리를 구분해 발견·표시하며 어느 트리도 복사하거나 소유하지 않습니다.

Workspace Explorer Activity는 파일 내용이나 Agent 실행 상태를 노출하지 않고, 임시 근거를 편집·이동·삭제·승격하지 않습니다. traversal과 symlink escape를 막고 깊이, 항목 수, 응답 크기를 제한하는 읽기 전용 metadata projection입니다.

출처: .agent-factory/agent/workspace-skill-work-request.md에 기록된 수락된 Human 결정과 현재 Workspace 에셋·초기화 계약.

09

관찰된 현재 구현

아래 내용은 목표 코어 모델의 완료 상태가 아니라 저장소에서 확인한 현재 구현 근거입니다.

관찰

현재 plugin surface는 다섯 Skills

metadata는 Agent, Convention, Gather, Document, Workspace에 해당하는 다섯 public Skills를 설명합니다. Explorer와 Interview는 별도 Skill이 아니라 일곱 핵심 역량 topology 안의 역량으로 유지됩니다.

출처: .codex-plugin/plugin.json, .agent-factory/agent/document-types-work/runs/run-20260830T070110807574Z-61393ff6/request.md

관찰

Explorer는 Work가 적용

skills/convention/references/explorer.md가 정보·provenance·권한 경계를 소유하고, Agent graph의 Work가 필요한 bounded evidence task에서 Explorer 역량을 적용합니다.

출처: skills/convention/references/explorer.md, skills/agent/SKILL.md

관찰

Main orchestration과 Interview

Main Agent는 Human 인터페이스, 적응형 Interview, orchestration, 통합을 소유합니다. skills/convention/references/interview.md가 지속적 정보·권한 경계를 소유하고 Main이 현재 대화에서 적용합니다. 필요한 배경 조사는 Work가 Explorer 역량으로 수행한 뒤 Interview를 재개할 수 있습니다.

출처: skills/convention/references/interview.md, skills/agent/prompt/main.md

관찰

Convention이 코어 의미를 소유

skills/convention/은 다섯 public Skills 중 하나로 코어 의미 모델, 일곱 역량의 관계, 느슨한 세 Document 유형, Skill 소유·작명, 저장소 독립 규칙을 제공합니다.

출처: skills/convention/SKILL.md, .agent-factory/agent/document-types-work/runs/run-20260830T072849765327Z-1f535f3f/request.md

관찰

Document가 세 유형을 정의

skills/document/는 Original, Processed, Specification의 정의를 소유합니다. Gather는 외부 동기화를 계속 소유하며 모든 Specification은 수락·조정된 프로젝트 지식과 필수 Human·AI 표현을 가집니다.

출처: skills/document/SKILL.md, skills/gather/SKILL.md

관찰

Workspace가 Human 관제탑을 소유

skills/workspace/가 공통 브라우저 셸, Activity navigation, local serving, workspace.sh launcher를 소유하고 로컬 UI는 .agent-factory/workspace/에 materialize됩니다.

출처: skills/workspace/SKILL.md, .agent-factory/agent/workspace-skill-work-request.md

관찰

Explorer 저장과 투영은 분리

.agent-factory/explorer/는 임시 Work/Explorer 근거 저장소이고, .agent-factory/workspace/explorer/는 프로젝트와 근거 트리를 분리해 표시하는 읽기 전용 Workspace Activity입니다.

출처: skills/workspace/references/interface.md, skills/convention/references/directory-structure.md

미해결 결정

다음 항목은 Human이 결정하기 전까지 목표 구조나 완료 상태로 간주하지 않습니다.

Human 소유

실행 계획과 수락 상태

roadmap 우선순위, deadline, owner, acceptance, risk acceptance, completion state는 이 명세에서 만들지 않았습니다.

미해결
