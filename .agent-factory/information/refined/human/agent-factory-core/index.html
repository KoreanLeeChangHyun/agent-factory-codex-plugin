02

정보 생명주기

01

원본 정보

출처의 의미와 형태에 충실하고, 어디에서 왔는지 추적할 수 있는 증거입니다.

  • 원문과 첨부 자료
  • 출처 식별자와 provenance
  • 수집 당시의 맥락
02

가공 정보

아직 신뢰할 수 있는 프로젝트 진실로 수락되지 않은 변환 결과입니다.

  • 분석과 비교
  • 가설과 연구 결과
  • 인터뷰 결과
03

정제 정보

충돌을 조정하고 Human이 수락한, 신뢰 가능한 프로젝트 지식입니다.

  • 합의된 결정과 요구사항
  • 정렬된 관계와 경계
  • Specification이 관리하는 지식

상태는 품질 등급이 아닙니다. 원본은 보존 가치가 있고, 가공은 탐색 가치가 있으며, 정제는 프로젝트 기준으로 수락되었다는 뜻입니다.

03

핵심 역량과 책임

역량주요 입력생성 또는 관리 정보책임 경계
GatherGoogle Drive, OneDrive, Slack, Notion, Discord 등 분산 출처원본출처 충실성과 provenance를 보존해 프로젝트에 필요한 정보를 수집합니다. 내용을 정제하거나 프로젝트 진실로 승격하지 않습니다.
Explorer웹, 코드, 문서, 원본과 가공 정보원본 가공분석하고 조사하며 탐색합니다. 원래 자료와 변환 결과를 만들 수 있지만 정제 정보의 수락 주체는 아닙니다.
InterviewHuman의 지식과 질문가공Main Agent가 현재 대화에서 적응형 인터뷰를 수행합니다. 필요한 배경 조사는 관리형 Explorer에 맡기고 대화를 재개하며, Explorer는 Human을 사칭하거나 인터뷰하지 않습니다.
Specification원본과 가공 정보, 수락된 Human 결정정제입력을 조정하고 수락된 하나의 의미 체계로 관리하며 Human과 AI 표현을 함께 유지합니다.
ConventionHuman이 정한 작업 제약전 단계 통제AI가 따라야 할 제약을 기록하는 약한 하네스로 생명주기 전체에 적용됩니다.
Agent역할, 권한, 맥락, 도구, 상태전 단계 실행다섯 공학 계층을 통합해 생명주기 전체의 AI Agent 실행을 담당합니다.

출처: .agent-factory/agent/agent-factory-core-spec-work-request.md에 기록된 수락된 Human 결정. 기존 Inquery 자료는 provenance를 보존한 채 .agent-factory/information/processed/legacy-inquery/로 이전되었습니다.

저장 위치가 달라도 provenance, authority, isolation, 의미 정렬, 접근성, 보안 요구는 유지됩니다. 원격 backend의 configuration, identity, sync/conflict, authentication, availability, caching은 미해결이며 구현된 것으로 간주하지 않습니다.

09

관찰된 현재 구현

아래 내용은 목표 코어 모델의 완료 상태가 아니라 저장소에서 확인한 현재 구현 근거입니다.

관찰

현재 plugin surface는 여섯 Skills

metadata는 Agent, Convention, Explorer, Interview, Specification, Gather에 해당하는 여섯 focused Skills를 설명합니다. 이것은 수락된 코어 역량 topology를 대체하는 목표 목록이 아닙니다.

출처: .codex-plugin/plugin.json

관찰

Explorer는 관리형 증거 탐색 구현

skills/explorer/SKILL.md는 provenance를 보존하는 임시 workspace와 resumable Explorer Agent 계약을 구현합니다. 원본 정보를 보존하거나 가공 정보를 만들 수 있지만 정제된 프로젝트 사실을 수락하지 않습니다.

출처: skills/explorer/SKILL.md

관찰

Main orchestration과 Interview

Main Agent는 Human 인터페이스, 적응형 Interview, orchestration, 통합을 소유하지만 실행 작업은 직접 하지 않습니다. 연구는 Explorer, 구현은 Work, 독립 검토는 Review, Human이 명시적으로 허가한 검증은 Verification에 위임합니다. Main은 필요한 Explorer 배경 조사를 사이에 두고 Interview를 재개할 수 있습니다.

출처: .agent-factory/agent/main-interface-orchestration-work/runs/run-20260827T185954481797Z-83e4ca60/request.md, skills/agent/references/main.md, skills/interview/SKILL.md

관찰

Convention이 코어를 소유

skills/convention/은 여섯 public Skills 안에서 코어 의미 모델, 정보 생명주기, Skill 소유·작명, 저장소 독립 규칙을 함께 제공합니다.

출처: skills/convention/SKILL.md, .agent-factory/agent/project-skill-naming-work-20260828/runs/run-20260827T185448822401Z-ef49909a/request.md

10

미해결 결정

다음 항목은 Human이 결정하기 전까지 목표 구조나 완료 상태로 간주하지 않습니다.

Human 소유

실행 계획과 수락 상태

roadmap 우선순위, deadline, owner, acceptance, risk acceptance, completion state는 이 명세에서 만들지 않았습니다.

미해결

외부 저장소 통합

backend configuration, identity, synchronization/conflict policy, authentication, availability, caching은 아직 결정되거나 구현되지 않았습니다.
