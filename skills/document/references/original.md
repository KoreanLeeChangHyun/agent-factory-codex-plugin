# Original Document

## Type contract

An Original (원본문서) is source-faithful evidence. Preserve source fidelity,
identity, provenance, collection context, and a native or source-appropriate
form. Original Documents may use diverse source formats; never impose one
canonical Original format.

Original is a Document type, not a quality, completeness, maturity, trust, or
authority judgment. An Original may remain Original without producing a
Processed Document or Specification.

## Relationships and provenance

Use the conceptual ordering `Original -> Processed -> Specification` only to
show a possible derivation or evidence relationship. Relationships may be
absent, one-to-many, many-to-one, or many-to-many. When a relationship exists,
preserve enough source identity, location, retrieval or collection context,
and transformation linkage for later inspection. Do not infer a required
transition, one-to-one mapping, completeness, or automatic promotion.

## Gather boundary

Gather owns locating, importing, refreshing, and mirroring external Documents
into a resolved destination. Document owns the Original type definition and
work on already-resolved Original targets. Gathering preserves source material;
it does not reconcile claims or promote evidence into a Specification.

An Original created or preserved by Explorer follows the same fidelity and
provenance rules. Explorer remains a Convention-owned capability applied in a
bounded Work task, not a public Skill.
