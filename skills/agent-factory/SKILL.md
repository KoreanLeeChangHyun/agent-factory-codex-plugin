# Agent Factory

Choose the entrypoint that matches the requested domain:

- `agents`: Agent roles for Human-facing lifecycle management and Goal-bound Work Unit execution.
- `factories`: Factory-wide lifecycle and evidence-backed rule capabilities.
- `intakes`: Intake creation, evidence synthesis, validation, readiness, and handoff.
- `specifications`: Canonical Project Core and Specification management.
- `work-units`: Work Unit planning, state management, execution, and worktree operations.
- `conventions`: Shared annotation and SVG icon conventions.
- `syncs`: Google Drive and Gmail workspace synchronization.
